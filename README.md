# CivicAI-OneGov 🏛️ - One Platform for All Govt Services

An AI-powered platform that unifies all government services in one place. Citizens can ask anything about government schemes, documents, and services - AI will guide them instantly.

## ✨ Features
- 🤖 AI Chat Assistant for govt queries
- 📄 All government services in one dashboard
- 💬 Smart chatbot - Ask in normal language
- 🌐 Responsive Design - Mobile & Desktop
- ⚡ Fast & Secure

## 🚀 Tech Stack
- **Frontend:** React.js, Vite, Tailwind CSS, JavaScript
- **Backend:** Node.js, Express.js
- **AI:** OpenAI API Integration
- **Version Control:** Git & GitHub
- **Deployment:** Vercel (Frontend) & Render (Backend)

## 🛠️ How to Run Locally

### 1. Clone the repo
git clone https://github.com/Koda-Bhavani/CivicAI-OneGov.git
cd CivicAI-OneGov

### 2. Run Backend
cd backend
npm install
npm run dev
-> Backend runs on http://localhost:5000

### 3. Run Frontend
cd frontend
npm install
npm run dev
-> Frontend runs on http://localhost:5173
